PROVEEDORES DE IA
Conexiones autorizadas por tu empresa
La empresa elige URLs del catálogo LLM. Tus permisos deciden si se inspeccionan. La política se consulta cada 30 segundos mientras gobiernas canales; expira si pasa una hora sin conexión.
Observación de conexiones desactivada
Activa una cuenta para descargar la configuración.
Navegadores del equipo
Chrome, Safari y otros navegadores que usen los ajustes de proxy y certificados de macOS. Se instala una CA TLS propia del equipo y un PAC que dirige únicamente los dominios LLM habilitados. La confianza de esa CA en el sistema abarca TLS; la selección de dominios la aplica Usovia.
La autorización se realiza en una ventana de macOS, sin abrir una consola. Al pausar o salir se restaura la conexión anterior; macOS puede solicitar otra autorización para retirar el certificado. Los navegadores con proxy o almacén de certificados propios requieren configuración de TI.
Sin activar
La cobertura de Gemini web usa el mismo adaptador en cualquier navegador compatible. Las webs de ChatGPT y Claude aún necesitan sus adaptadores de conversación; conectar TLS no equivale a clasificar sus mensajes. Reinicia o recarga el navegador si conserva conexiones anteriores.
Conexiones en Windows
Utiliza Gemini en el navegador de Usovia o configura una API compatible con el proxy local. El lanzador de Gemini CLI requiere la instalación global con npm. Esta versión no modifica los certificados ni el proxy de los demás navegadores de Windows.
